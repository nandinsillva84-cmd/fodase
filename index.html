1. Conexão com o GitHub

Como criar o token
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Em Repository access, escolha só este repositório.
  3. Em Permissions, deixe Contents e Actions em Read and write.
  4. Gere o token, copie e cole acima.

2. Escolha seu app ou jogo
